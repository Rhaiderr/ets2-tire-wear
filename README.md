# Tire Wear para ETS2 e ATS

Plugin de desgaste visual de pneus e estouros com retorno de força no volante.

- [Baixar Tire Wear 0.3.2 estável (ZIP)](https://github.com/Rhaiderr/ets2-tire-wear/releases/download/v0.3.2/ets2-tire-wear.zip)
- [Ver versões e notas de lançamento](https://github.com/Rhaiderr/ets2-tire-wear/releases)
- [Encontrar outros mods no Mod Hub](https://rhaiderr.github.io/mod-hub/)

Testado no ETS2 e ATS 1.61 em modo single player, no Windows 10/11 de 64 bits com DirectX 11.

## Instalação

Com o jogo fechado, extraia `ets2_tire_wear.dll` e `ets2_tire_wear.ini` para `bin/win_x64/plugins` na pasta do jogo. Crie a pasta `plugins` se necessário. Ao atualizar, preserve seu INI se já tiver uma configuração própria.

## English

Tire Wear adds visual tire wear and blowouts with force feedback to ETS2 and ATS. Tested on version 1.61 in single player. With the game closed, extract the DLL and INI to `bin/win_x64/plugins` in the game folder. Keep your existing INI when updating if you have customized it.
